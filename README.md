# Robomaster
大一RM新人，记录在3SE重装组的电控学习过程。

## 开发环境
Windows + VS Code + ARM Keil Studio Pack(CMSIS) + pyOCD烧录
工程由STM32CubeMX生成MDK-ARM后，转换为CMSIS工程。

## UART串口通信
达妙STM32H723VGTx开发板 + ST-Link 下载器

## CAN通信电机控制
达妙STM32H723VGTx开发板 + DJI C620 电调 + DJI 3508 电机 + ST-Link 下载器

## PID电机控制
达妙STM32H723VGTx开发板 + DJI C620 电调 + DJI 3508 电机 + ST-Link 下载器
